## 進行ルール

1. **タスクは小さく**: 1タスク = 1〜4時間。超えるなら分割
2. **観測可能なクリア条件** を必ず明記
3. **テストファースト**: domain は先にユニットテストを書く
4. **完了 = PR がマージ済み + CI緑 (lint/typecheck/test) + 3プラットフォーム動作確認**
5. 仕様変更は [[requirements]] / [[design]] / [[skills]] に同期更新
