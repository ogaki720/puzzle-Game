# 要件定義 — もちポップ (MochiPop)

## 1. プロダクト概要

「ゆるかわアニマル」をテーマにした **マッチ3パズルゲーム**。Android / iOS / Web で動作するクロスプラットフォーム作品。1000ステージ以上の長期プレイを支える設計とし、短い隙間時間でも長時間でも遊べる「ハマる」ループを目指す。

- **タイトル**: **もちポップ** (MochiPop)
- **キャッチコピー**: もちもちアニマルが、ぷにっと弾ける。
- **対象プラットフォーム**: Android 8.0+ / iOS 13+ / モダンブラウザ (Chrome/Safari/Edge)
- **エンジン**: **Expo SDK 51+** (React Native + react-native-skia) — 単一コードベースで iOS / Android / Web をビルド
- **ターゲット**: カジュアル層 (10〜50代)、スキマ時間+寝る前の長時間プレイ層
- **核となる体験**: 「もちもちキャラがぷにっと弾ける気持ちよさ × ステージクリアの達成感 × 次が気になる演出」

## 2. ペルソナ

| ID | 名前 | 行動 | 求めるもの |
|---|---|---|---|
| P1 | カジュアル ミナさん (32) | 通勤電車で5〜10分、夜に30分 | テンポ良くクリアできる、可愛い演出 |
| P2 | ガチ勢 ケンジ (24) | 週末に2時間以上 | 高難度ステージ、最適解探し、コンボ快感 |
| P3 | コレクター ユイ (40) | 毎日10分、コツコツ | キャラ収集、図鑑、デイリー報酬 |

## 3. ユーザーストーリー & 受け入れ基準 (EARS)

### US-1: ステージプレイ
**As a** プレイヤー  
**I want** マッチ3パズルをプレイしたい  
**So that** 気持ちよく時間を潰したい

- AC-1.1: システムは 6×7 〜 9×9 のグリッドにキャラを配置すること
- AC-1.2: プレイヤーが隣接する2マスをスワイプしたとき、**3つ以上の同種キャラが揃う場合のみ** 入れ替えが成立すること
- AC-1.3: マッチが成立したとき、システムは該当キャラを消去し上から新キャラを落下補充すること
- AC-1.4: 連鎖（落下後に新たなマッチ）はスコア倍率を加算すること (1連鎖 = ×1.0, 2連鎖 = ×1.5, 3連鎖以降 = ×2.0…)
- AC-1.5: 4つ揃い・5つ揃い・L字・T字で **特殊キャラ** が生成されること ([[skills]] 参照)

### US-2: ステージ目標
**As a** プレイヤー  
**I want** ステージごとに違う目標で遊びたい  
**So that** 飽きずに長く遊びたい

- AC-2.1: 各ステージは以下のいずれかの目標タイプを持つこと: `score` / `collect` / `clear_obstacle` / `bring_down` (アイテム降下) / `rescue` (キャラ救助)
- AC-2.2: 手数制限（または時間制限）を超えた場合、ステージ失敗とすること
- AC-2.3: 目標達成時、残り手数を **ボーナス演出** に変換すること
- AC-2.4: 星3つ評価 (達成スコア帯に応じて ★1/★2/★3) を表示すること

### US-3: 進行・ステージ管理
**As a** プレイヤー  
**I want** マップで進行を一望したい  
**So that** 達成感と次の目標が明確になる

- AC-3.1: システムは **ワールド (10ステージ単位)** で区切られたマップを提供すること
- AC-3.2: クリア済みステージのみ再プレイ可能、未到達ステージはロックされること
- AC-3.3: 最低 **1000ステージ** 分のステージデータを提供可能な仕組みを持つこと (JSONで定義)

### US-4: ライフ (ハート) システム
**As a** 運営  
**I want** 連続プレイに上限を設けたい  
**So that** リテンションを設計したい

- AC-4.1: プレイヤーは最大5ハートを保有でき、失敗時に1ハート消費すること
- AC-4.2: ハートは **30分に1回回復** すること
- AC-4.3: ハート0時はプレイ不可、回復待ち時間を表示すること
- AC-4.4: フレンドから/広告視聴/課金 でハート補充ができること (※マネタイズ層はフェーズ2)

### US-5: キャラ収集 / 図鑑
**As a** コレクター  
**I want** キャラを集めて眺めたい  
**So that** やり込みのモチベーションが続く

- AC-5.1: ステージクリア報酬として **キャラの欠片** を入手できること
- AC-5.2: 欠片n個でキャラ解放、図鑑に登録されること
- AC-5.3: 解放キャラはホーム画面の **マスコット** として配置できること
- AC-5.4: キャラごとに固有の**ボイス/モーション**が再生されること

### US-6: ブースター / アイテム
- AC-6.1: プレイヤーは事前準備で最大3種類のブースターを所持可能なこと
- AC-6.2: プレイ中アイテム（ハンマー/シャッフル/+5手）が使用可能なこと
- AC-6.3: 詳細仕様は [[skills]] に記載

### US-7: 永続化・オフライン
- AC-7.1: ゲーム進行 (クリアステージ・所持キャラ・ハート残数) はローカル永続化されること
- AC-7.2: オフラインでもプレイ可能であること
- AC-7.3: フェーズ2でクラウドセーブ (任意ログイン) を導入できる構造にしておくこと

### US-8: パフォーマンス・操作感
- AC-8.1: スワイプ操作の応答は **100ms以内** に視覚反応すること
- AC-8.2: 60fpsを目標とし、フレーム落ちなく描画されること (ローエンド端末は30fps許容)
- AC-8.3: 初回起動からタイトル表示まで **3秒以内** (キャッシュあり)

### US-9: アクセシビリティ / 多言語
- AC-9.1: 日本語/英語のテキスト切替に対応すること
- AC-9.2: 色覚多様性配慮: キャラは **色+形** で区別可能とすること
- AC-9.3: BGM/SE/ボイスは個別音量調整できること

---

> 以下 US-10〜US-21 は [[review]] の批判的レビューに基づく「ハマる強化パック」。各ストーリーは **MVP** か **Phase 1.5** のフェーズマーカ付き。

### US-10: 動的難易度調整 (DDA) [MVP]
**As a** カジュアル プレイヤー
**I want** 連続失敗時にさりげなく助けてほしい
**So that** 折れずに続けられる

- AC-10.1: 同一ステージで **3回連続失敗** した場合、次回プレイで補充ピース色を目標寄りに **+10%偏らせる** こと
- AC-10.2: 残手数0時、**初回のみ「+5手 (無料)」** ダイアログを表示すること
- AC-10.3: DDA 介入はプレイヤーに気づかれないように行い、内部ログにのみ記録すること

### US-11: マスコットガイド [MVP]
**As a** プレイヤー
**I want** 可愛いキャラに励まされたい
**So that** ゲームへの愛着が湧く

- AC-11.1: ホーム画面の **もちうさ** マスコットは アイドル/手振り/眠る の3状態を切り替えること
- AC-11.2: ステージ クリア時に **もちうさが祝福演出** (跳ねる + ボイス) を再生すること
- AC-11.3: ステージ 失敗時に もちうさが **悲しい顔 + 励ましセリフ** を表示すること
- AC-11.4: 失敗ダイアログのデフォルトボタンは「もう一回」とすること

### US-12: オンボーディング [MVP]
**As a** 初回プレイヤー
**I want** スムーズに操作を覚えたい
**So that** 最初の数分で離脱しない

- AC-12.1: ステージ 1〜3 は **失敗不可能な難度** (絶対クリア感) に調整されていること
- AC-12.2: ステージ 5 で Striped、ステージ 8 で Wrapped、ステージ 12 で Rainbow を **演出付きでデビュー** させること
- AC-12.3: ステージ 1〜20 は **ハートを消費しない** こと
- AC-12.4: 操作チュートリアルは **必要箇所のみ** スポット表示し、スキップ可能とすること

### US-13: ニアミス強化 [MVP]
**As a** プレイヤー
**I want** あと一歩で勝てる感覚を強めたい
**So that** リトライしたくなる

- AC-13.1: 残手数が **3以下** になったとき、画面端の時計マークが脈打つこと
- AC-13.2: 目標の **80%以上** を達成して失敗した場合、リザルトに「あと少し！」演出を表示すること
- AC-13.3: 失敗ダイアログで **「+5手 (動画視聴 or コイン消費)」** をデフォルト選択にすること

### US-14: デイリー & チェスト [MVP]
**As a** リピーター
**I want** 毎日違うチャレンジで遊びたい
**So that** 毎日起動するきっかけになる

- AC-14.1: 毎日3個の **デイリーミッション** を提示すること (例: Striped を5個作る、3000点取る)
- AC-14.2: ミッション達成で **デイリーチェスト** を獲得できること
- AC-14.3: チェストは **コモン/シルバー/ゴールド** の3レアリティを持ち、開封演出 (1秒の溜め + 光る瞬間) を再生すること
- AC-14.4: 連続ログイン日数を表示し、7日サイクルで報酬テーブルを開放すること

### US-15: プッシュ通知 [MVP]
**As a** プレイヤー
**I want** 復帰のきっかけを得たい
**So that** ゲームを忘れずに継続できる

- AC-15.1: ハート満タン時に通知を送ること (許諾済みの場合)
- AC-15.2: デイリーミッション リセット時刻 (ローカル12:00) に通知を送ること
- AC-15.3: 連続ログイン途切れ前日に **警告通知** を送ること
- AC-15.4: 通知設定は ON/OFF を **カテゴリ別** に切替可能とすること
- AC-15.5: 通知許可はオプトイン、初回起動時には要求しないこと (子供向け配慮)

### US-16: ジューシー演出基準 [MVP / 非機能]
**As a** プレイヤー
**I want** 触ったときの気持ちよさを最大化したい
**So that** プレイ自体が報酬になる

- AC-16.1: マッチ消去演出は入力から **60ms以内** に開始すること
- AC-16.2: スコアテキストは マッチ位置から **250ms** で HUD に吸い込まれること
- AC-16.3: 連鎖数 n に応じて カメラシェイク強度を **線形 (上限 n=5)** で増加させること
- AC-16.4: 4連鎖以上で **画面ズーム + 「Excellent」演出** を 200ms 再生すること
- AC-16.5: SE のピッチを連鎖数ごとに半音ずつ上昇させること

### US-17: メタ進行 もちもちタウン [Phase 1.5]
**As a** 長期プレイヤー
**I want** クリアの努力が街の発展として可視化されてほしい
**So that** やり込みが続く

- AC-17.1: 獲得した ★ を消費して **タウンの建物/オブジェクト** を修復/装飾できること
- AC-17.2: ワールドクリアで **新エリア** (もちうさハウス / みんとカフェ / れもひよ広場 …) が開放されること
- AC-17.3: タウン画面でキャラがランダムに歩き回り、タップで反応すること

### US-18: ナラティブ [Phase 1.5]
**As a** プレイヤー
**I want** ステージの背景に物語を感じたい
**So that** 「次が気になる」体験を得る

- AC-18.1: 各ワールドの 開始/終了 で **静止画コミック形式の1分エピソード** を表示すること
- AC-18.2: エピソードは **スキップ可能** とし、後から Codex 内の図書館で再生できること

### US-19: 期間限定キャラ (FOMO) [Phase 1.5]
**As a** 運営
**I want** 月1回の限定キャラで習慣化を促したい
**So that** 長期リテンションを設計する

- AC-19.1: 月1回のイベント期間中のみ **限定キャラ (例: さくらもちうさ)** の欠片を入手可能とすること
- AC-19.2: イベント終了後、限定キャラは **復刻** でのみ入手可能とすること
- AC-19.3: イベント残り時間を ホーム画面で可視化すること

### US-20: ストリーク [Phase 1.5]
**As a** 習慣化プレイヤー
**I want** 連続記録で励まされたい
**So that** プレイの習慣を維持する

- AC-20.1: 連続クリア (ノーリトライ) で **コンボラリー** バッジを獲得できること
- AC-20.2: 連続ログイン 7日/14日/30日 で限定報酬を獲得できること
- AC-20.3: ストリーク途切れの **猶予 (グレース) 1日** を月1回付与すること

### US-21: 軽量ソーシャル [Phase 1.5]
**As a** プレイヤー
**I want** 友人と緩く繋がりたい
**So that** モチベーションが続く

- AC-21.1: フレンドコードで **招待/承認** ができること (アカウント登録不要)
- AC-21.2: 週間スコア ランキング (匿名アバター可) を表示すること
- AC-21.3: 1日1回 フレンドに **ハートをプレゼント** できること

## 4. 非機能要件

| 項目 | 目標 |
|---|---|
| 起動時間 | 3秒以内 (キャッシュあり) |
| バイナリサイズ | Android 80MB / iOS 150MB 以内 (Hermes + Expo Updates 想定) |
| ストレージ | プレイデータ 10MB以内 |
| クラッシュフリー率 | 99.5%以上 |
| 操作レスポンス | 100ms以内の視覚フィードバック |

## 5. スコープ外 (Phase 2 以降)

- PvP / オンライン対戦
- ギルド / ヘビーソーシャル (チャット/チーム戦)
- クラウドセーブ・アカウント同期
- 課金導入 (IAP)
- ガチャ確率 / 重課金導線
- 本格イベント運用基盤 (ストアフロント込み)
- 広告クリエイティブ用「Save the Dog」型ミニステージ
