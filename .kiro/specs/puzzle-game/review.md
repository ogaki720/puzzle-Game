# レビュー — もちポップ (MochiPop)

「このパズルは面白いか？」「ハマるポイントは設計されているか？」に対する **批判的レビュー** + **2025〜2026 年のモバイルパズル市場調査** をまとめ、現仕様の改善提案を出す。

---

## エグゼクティブサマリー

> **現状の評価**: 技術設計は堅実だが、**「ハマる」設計は MVP として薄い**。マッチ3の基本ループ・ステージ制・ハート制・収集系は揃っているが、 **メタ進行 (拠点デコ)・物語・救済 (DDA)・社交・FOMO・期間限定イベント** が欠落。Royal Match / Block Blast 等2025トップ作の構造と比較すると、**「やめられない理由」が不足** している。
>
> **結論**: 現仕様だけでリリースしても「よく出来たマッチ3」止まりで、CPI を回収するリテンションは出にくい。**Phase 1.5** として §5「ハマる強化パック」 (本書) の導入を強く推奨。

## 1. 市場調査 — 2025〜2026 モバイルパズルの実勢

### 1.1 グローバル トップ層

| 順位帯 | タイトル | 開発 | 特徴 |
|---|---|---|---|
| **最強DL層** | **Block Blast!** | Hungry Studio | 2025/2026連続でDL数世界一位。366M+ DL。**広告主導・超シンプル・無限プレイ**。Tetris派生 |
| 最強収益層 | **Royal Match** | Dream Games | 2024-2025 グロッシング1位。$1.3B/year。マッチ3 + **王宮デコ + 救済キャラ "King" 演出** |
| 王道 | **Candy Crush Saga** | King | 12年継続。ARPDAU $0.11、Royal Matchは$0.17 |
| 物語派生 | **Gossip Harbor / Gardenscapes / Homescapes** | Microfun / Playrix | マッチ3 + **エピソード型ナラティブ** |
| 爆破系 | **Toon Blast / Toy Blast** | Peak Games | キャラ・物語駆動 |

### 1.2 日本トップ層

| タイトル | 特徴 |
|---|---|
| **パズル&ドラゴンズ** (パズドラ) | パズル×RPG、キャラガチャ。日本最強売上の一角 |
| **ディズニー ツムツム** | キャラIP×なぞって消す。LINE社運営 |
| **妖怪ウォッチ ぷにぷに** | IP×タップ消し、爽快感 |
| **ロイヤルマッチ** (日本でも上位) | 海外ヒットが日本でも定着 |
| **トゥーンブラスト** | 海外勢の定番 |

### 1.3 2025-2026 の主要トレンド

1. **ハイブリッドカジュアル** がジャンルを横断: 軽量コア + 中重度メタ
2. **ブロックパズル復権**: Block Blast の独走でレッドオーシャン化
3. **物語×マッチ3** が課金最強層: Royal Match / Homescapes 型
4. **ライブオプスが必須**: デイリー / シーズン / 期間イベントなしでは Day7 リテンション維持不可
   - パズル全体の Day7 リテンションは **12% → 11% に低下** (2024-25年)
5. **救済演出 (Save the X)** が広告クリエイティブの主流
   - 「犬を助ける」「お姫様を救う」など。実ゲームに無くても広告は釣れる
6. **コレクション系UI** (スタンプブック・図鑑) が普及
7. **PvP マッチ3** (Match Masters) が成長中
8. **超シンプル系**: Block Blast が証明したように、シンプル=正義
9. **3D Triple Match** (Match Factory / Tile Match) が新興ジャンル
10. **広告と本編が違うゲーム** 問題 → 「広告どおりの内容」を準備する流れ

### 1.4 「ハマる」の心理学 (調査ソース整理)

- **可変報酬** (スキナー箱): 同じマッチでも稀に大爆発・大コンボ
- **コントロール錯覚**: ブースター/アイテムで「次こそ自分の力で」と思わせる
- **サンクコスト**: ステージ進行・キャラ収集による「やめにくさ」
- **ザイアンス効果**: 繰り返し接触 → 好意増大 (キャラ・BGM・操作感)
- **ニアミス効果**: 「あと1手で勝てた」がリトライ動機を最大化
- **おあずけ報酬**: ハート制限 → 戻ってきたくなる
- **食感連想**: 「もちもち」「ぷにっと」「キャンディ」など、口感の快を視覚に移植

## 2. 現仕様 (requirements / design / skills / tasks) の批判的レビュー

### 2.1 良い点 (Strengths)

| 領域 | 評価 |
|---|---|
| 技術選定 | Expo + Skia + Zustand + MMKV はモダンかつ妥当。3プラットフォーム対応も射程内 |
| EARS要件 | 受入基準が明確、テスト可能 |
| マッチエンジン | コンボ6種、特殊4種は基本網羅。RNGシード再現性◎ |
| 障害物 | 6種は十分なバリエーション |
| アクセシビリティ | 色+形での区別、3チャンネル音量、ja/en は競合より丁寧 |
| 永続化 | schemaVersion 付き、Web fallback も設計済み |

### 2.2 課題 (Critical Gaps) — 「ハマる」観点

| # | ギャップ | 影響 | 比較対象 |
|---|---|---|---|
| **G1** | **メタ進行 (拠点デコ・物語) なし** | リテンションが Day3 で壁 | Royal Match / Homescapes |
| **G2** | **ナラティブ なし** | 「次が気になる」が出ない | Toon Blast / Gossip Harbor |
| **G3** | **DDA (動的難易度) なし** | 失敗連発で離脱 | Candy Crush の隠し救済 |
| **G4** | **救済キャラ (マスコット演出) なし** | エンゲージ瞬間が薄い | Royal Match の King |
| **G5** | **デイリー / シーズン / イベント** がフェーズ2送り | Day7リテンション持たない | 全トップ作 |
| **G6** | **FOMO (期間限定キャラ/報酬)** なし | リアルマネー化困難 | パズドラ / ツムツム |
| **G7** | **オンボーディング設計 詳細なし** | 初期離脱が起きる | Royal Match の超丁寧tutorial |
| **G8** | **「あと1手で…」演出** なし | リトライ率不足 | Candy Crush の "+5 Moves" |
| **G9** | **チェスト/宝箱演出** なし | 可変報酬の快感不足 | Royal Match のスタンプブック |
| **G10** | **広告クリエイティブ用フック** なし | UA困難 | Save the Dog 系 |
| **G11** | **ソーシャル/協力/ランキング** なし (MVP) | 長期維持困難 | Candy Crush友達招待 |
| **G12** | **連続ログイン/連続クリア ストリーク** なし | 習慣化弱い | Duolingo型ストリーク |
| **G13** | **プッシュ通知設計 なし** | 復帰トリガー欠落 | 全トップ作 |
| **G14** | **「気持ちよさ」演出 数値目標 なし** | 開発判断ブレる | "Juiciness" の定量化 |
| **G15** | **広告/IAP 設計 (フェーズ2)** | 収益不能 | (収益化前提なら必須) |

### 2.3 「面白いか」の率直な評価

- **コアゲーム単体** としては Candy Crush 同等以上の完成度を出せる設計
- ただし **2026年の市場で「ハマる」には足りない**
- 同種ジャンルに Royal Match / Block Blast / パズドラ / ツムツム という巨人がいるため、**「もちもちアニマル」というIPの強さ × 演出の気持ちよさ × メタゲーム** の三点突破が必要
- もち/ぷに のオノマトペは食感連想で **正しい武器** (Candy Crush と同じ系譜)。これを最大限に活用すべき

## 3. 推奨追加機能 — 「ハマる強化パック」

requirements.md / design.md / skills.md / tasks.md に **MVP に含めるべき追加要素** として書き戻し提案。

### 3.1 メタ進行: もちもちタウン (拠点デコ)

- ★獲得 → タウンの建物/オブジェクトを修復・装飾
- もちうさハウス / みんとカフェ / れもひよ広場 …
- ワールド単位で **大きなアンロック** (新エリア解放)
- 効果: **Day7→Day30 リテンションの主要ドライバ**

### 3.2 ナラティブ: もちタウンの物語

- ワールドごとに 1〜2 分の小エピソード (動かないコミック形式で軽量)
- 「タウンに災害が…」「迷子のもちうさを助けて」など
- 効果: 「次のステージが気になる」を作る

### 3.3 DDA (動的難易度調整)

- 3回連続失敗で **隠し救済**: 補充ピースの色を目標寄りに偏らせる (5%程度)
- 残手数0時に **「+5手 (1回無料)」演出** → 初回はリトライ用ブースター無料
- 効果: 離脱率劇減

### 3.4 マスコット演出: ガイドキャラ

- ホーム/失敗/クリア時に **もちうさ** が反応
- 失敗時:「もう一回いっしょにがんばろ？」 → リトライCTA
- 効果: 感情的なつながり、Royal Match の King 型

### 3.5 デイリー / シーズン

- **デイリーミッション** 3個 (例: 「Striped を5個作る」)
- **デイリーチェスト** (24h ごと)
- **連続ログイン** 7日サイクル
- **シーズン (28日)** で限定キャラ欠片 + 限定タウンパーツ
- 効果: 翌日復帰率の決定的向上

### 3.6 期間限定 (FOMO)

- 月1回 **イベント限定キャラ** (例: 「さくらもちうさ」)
- イベント期間中のみ入手可、終了後は復刻ガチャでのみ
- 効果: リアルマネー化への伏線、習慣化

### 3.7 オンボーディング

- **最初の3ステージは絶対クリア感** (失敗不可能な難度)
- 5ステージで Striped 演出、8ステージで Wrapped、12でRainbow を **演出デビュー** (Royal Match 流)
- 20ステージまでは ハート無消費 (失敗してもOK)
- 効果: 初期離脱率減

### 3.8 ニアミス強化

- 残手数3以下で **画面端に時計マークが脈打つ**
- 失敗直前に **「あと1手あれば届く位置」を視覚強調**
- 失敗ダイアログのデフォルトボタンを「+5手 (動画視聴)」に
- 効果: リトライ転換率の最大化

### 3.9 スタンプブック / チェスト

- 1ステージクリアで **コインドロップ** + 稀に「ぴかチェスト」
- チェスト開封演出 (1秒の溜め → 開く瞬間に光る) → ★ボーナス
- スタンプ収集ページ (= 図鑑とは別軸の進行)
- 効果: 可変報酬の中毒性

### 3.10 ストリーク

- 連続クリア (ノーリトライ) で **コンボラリー** バッジ
- 7日連続ログインで限定タウンパーツ
- 効果: Duolingo型習慣化

### 3.11 プッシュ通知設計

- ハート満タン (即時)
- デイリーミッションリセット (12:00)
- 連続ログイン途切れ警告 (前日同時刻)
- イベント開始/終了2時間前
- 効果: D1, D7, D30 リテンション底上げ

### 3.12 「ジューシー」定量化

- マッチ後 60ms 以内に演出開始
- カメラシェイク強度を連鎖数で線形
- スコアテキストは 250ms で HUD 吸い込み
- 大コンボ時は 200ms カメラズーム
- 効果: 「気持ちよさ」を仕様化、PR 差し戻し基準にする

### 3.13 広告クリエイティブ用フック (任意)

- 「もちうさを救え！」ミニステージ (実本編にも入れる)
- 倒した障害物の数で「もちうさが救われる」演出
- 効果: UA クリエイティブと本編の一致 (規約遵守)

### 3.14 ソーシャル (フェーズ1.5 — 軽量)

- フレンドコード招待 (深い社交は無し)
- 週間スコアランキング (匿名アバター)
- ハート プレゼント
- 効果: 完全ソロより滞留が伸びる
