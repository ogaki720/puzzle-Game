# スキル・特殊ピース・ブースター定義

「気持ちよさ」と「奥深さ」を支える特殊要素を集約。すべて [[design]] のマッチエンジン/スコアリングと整合させること。

## 1. 基本キャラクター (もちアニ 6種)

| ID | 名前 | カラー | モチーフ | ボイス例 |
|---|---|---|---|---|
| `berry` | もちうさ | ピンク | うさぎ × いちご大福 | 「ぴょん♪」 |
| `mint` | みんとくま | ミントグリーン | くま × ミント | 「もぐ…」 |
| `lemon` | れもひよ | イエロー | ひよこ × レモン | 「ぴよぴよ！」 |
| `sky` | そらぺん | スカイブルー | ぺんぎん × ラムネ | 「ぱくっ」 |
| `peach` | ももぱんだ | コーラルピンク | パンダ × もも | 「ふわぁ」 |
| `plum` | うめねこ | パープル | ねこ × 梅 | 「にゃむ」 |

> **アクセシビリティ**: 色だけでなく **形（耳/しっぽ）+ 模様** で識別可能にする。色覚多様性配慮 (AC-9.2)。

## 2. 特殊ピース (盤面で生成)

| ピース | 生成条件 | 効果 | 視覚 |
|---|---|---|---|
| **Striped 横** | 横に4連揃え | 起動時、その**行全体**を消去 | キャラに横ストライプ |
| **Striped 縦** | 縦に4連揃え | 起動時、その**列全体**を消去 | キャラに縦ストライプ |
| **Wrapped (爆弾)** | L字 / T字 揃え | 起動時、**3×3を2回**爆発 | 包帯ぐるぐる |
| **Rainbow (虹)** | 直線5連揃え | スワップした相手色のピースを**全消去** | 虹色オーラ |

| 組み合わせ | 効果 | 演出 |

| Striped × Wrapped | **行3本+列3本** を消去 (太い十字) | 太線レーザー |
| Wrapped × Wrapped | **5×5を2回** 爆発 | 大爆発 |
| Rainbow × Striped | 同色を全部Striped化して起動 | 縞模様カスケード |
| Rainbow × Wrapped | 同色を全部Wrapped化して起動 | 連続爆発 |

## 9. スコア計算式

```
base       = matched_count * 10
combo_mult = 1.0 + 0.5 * (chain_index - 1)   # 1連鎖=1.0, 2=1.5, 3=2.0...
special    = (生成した特殊ピース数) * 60
score     += (base + special) * combo_mult * boost
```

- `boost`: `score_boost` ブースター発動中なら2.0
- 1ステージ最大スコアの目安: ★3閾値 = 平均クリア時の1.5〜2倍

## 10. バランス指標 (初期値)

| 指標 | 目標 |
|---|---|
| 平均クリア手数 / 制限手数 | 0.75 |
| 1ステージ平均プレイ時間 | 60〜90秒 |
| 失敗率 (新規ステージ) | 30〜45% (リテンション最適) |
| 1ワールド (10ステージ) 進行時間 | 15〜25分 |
| ★3達成率 | 30〜50% |

> 数値は実機テスト後にチューニング。`assets/stages/*.json` をホットスワップ可能にして調整サイクルを早める。

## 14. デイリーミッション 型 — US-14

| 型 | パラメータ | 例 | 推定所要 |
|---|---|---|---|
| `make_special` | subtype, count | Striped を 5個作る | 3〜5ステージ |
| `reach_score` | value | 3000点取る | 1〜2ステージ |
| `clear_stages` | count | 3ステージクリア | 3ステージ |
| `collect_color` | color, count | Berry を 30個消す | 1〜3ステージ |
| `no_fail` | count | 2ステージ連続ノーリトライ | 2ステージ |

毎日3個提示。**必ず1個は確実達成可能な低難度**。難度バランスは A/B テストで調整。

### 15.2 入手フロー

- イベント開始 → 期間限定ステージ群開放 (10ステージ)
- クリアで限定キャラ欠片を入手 (n個で解放)
- イベント終了後は **復刻ガチャ** でのみ入手可
- 通常キャラの色違いではなく、**専用衣装/モーション/ボイス** を持つ

### 15.3 ホーム画面でのカウントダウン

- イベント残り時間を時計UIで表示
- 残り24h で **「ラストスパート」** バナー
- 残り1h で **赤強調 + 通知**
